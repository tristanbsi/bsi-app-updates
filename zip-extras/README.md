# What goes in each first-install zip

`tools/make-drive-zip.sh` copies everything in `zip-extras/<app>/` (except this README) next to the app inside
the zip. Keep here:
- `READ ME FIRST.txt` — the same text that sits in the Drive folder as "<App> - how to install.txt"
- sample files (StandBy: the Cornell Homecoming sample show CSV, copied from the previous zip)

Edit the READ ME here, rebuild the zip, then replace both files in Drive.
